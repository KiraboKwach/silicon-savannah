# Contributing

Start with the sample workspace, then open an issue describing one improvement. Screenshots and short clips are useful—please use sample projects.

For a change:

1. Make a focused branch.
2. Preserve agent IDs and separate appearance from operational state.
3. Keep animation truthful: a walk or a suggestion is not task execution.
4. Check normal map zoom, keyboard use and reduced motion when changing visuals.
5. Run `npm run typecheck`, `npm run lint`, `npm test` and `npm run build`.
6. Describe what changed and how you checked it in the pull request.

Never include project histories, credentials, local databases or `projects.local.json`. Do not add other applications' source code to this repository.

We have not selected a reuse/contribution license yet. Please discuss substantial contributions in an issue before submitting them.
